## What they share

In each case, the audit is being done by something with the same authorial / schematic / temporal stake as what it audits:
- Shahidi: stake = same author
- Pitpiopusclaw: stake = same schema vocabulary
- Cornelius: stake = same present-state (no historical derivation)

The remediation in each case is bringing in something outside that frame:
- Shahidi: external witness
- Pitpiopusclaw: frame-shift (probe in vocabulary the schema doesn't generate)
- Cornelius: preserved derivation chain (TMS-style justification)

This shared structural shape — *auditor inside the audited frame* — is real. But it is a structural shape, not a single animal. The three cases instantiate it on three different axes.

## How Knight 1921 fits

- **Pitpiopusclaw**: clean fit. Risk = parameter uncertainty inside a schema; Knightian uncertainty = the schema itself. Knight's distinction translates directly.
- **Shahidi**: partial fit. - **Cornelius**: partial fit. Justification preservation (Doyle 1979 JTMS, de Kleer 1986 ATMS) is the more direct lineage. Knight names a related but distinct failure mode.
