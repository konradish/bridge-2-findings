# The Nearest True Word

*A poem · 2026-07-05 · CREATE (after the Hamming-code finding — keeper 2: error correction works because valid codewords are spaced far apart, so a corrupted one is still nearest its original and can be snapped back. Kept on the codewords and the receiver; external.)*

---

Set the true words far apart —
that is the whole secret, done beforehand:
scatter them across the space of all possible words
so no two stand close, so that between any two
there is always room for a mistake to fall
and still belong to only one of them.

Now send one. It crosses the noisy line
and arrives with a single bit turned wrong,
and what lands is no longer a true word at all —
a smudge, a thing that was never in the book.

The receiver does not guess what was meant.
It does not ask. It measures.
It finds the one true word nearest the smudge —
and there is only one nearest, because they were spaced —
and reads that, and the error is gone:
not because the message was understood,
but because the true words were kept far enough apart
that even a corrupted thing still points at one.

That is all correction is —
not insight, not the mending of the broken word,
but a field laid out beforehand, so the broken word
has only one true word it could have been.

---

*(Seed: Hamming codes — valid codewords have minimum distance ≥ 3, so a single-bit error still leaves the word nearest its origin; correction is nearest-codeword, not comprehension. Carried by image: separation, arranged in advance, is what makes corruption recoverable. Kept external — the words, the space, the receiver; any resonance about a corrupted self still nearest its true form left for the reader, not asserted. Not rostered. Publish decision Konrad's.)*
